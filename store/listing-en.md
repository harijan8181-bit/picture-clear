## App name (최대 30자)

```
Photo Info Eraser: EXIF & GPS
```

## Short description (최대 80자)

```
Remove GPS location & EXIF from photos. Blur faces and hide labels, offline.
```

## 데이터 보안(Data safety) 양식 답변 가이드

| 질문 | 답변 |
| --- | --- |
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **예** (AdMob 때문) |
| 전송 중 데이터 암호화 | 예 (AdMob은 HTTPS 사용) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 아니요 (앱이 직접 수집하는 데이터 없음) |
| 기기 또는 기타 ID → 광고 ID | 수집 ✔ · 공유 ✔ · 목적: 광고 또는 마케팅, 분석 |
| 위치 → 대략적인 위치 | 수집 ✔ (AdMob이 IP로 추정) · 목적: 광고 |
| 앱 활동 → 앱 상호작용 | 수집 ✔ (AdMob) · 목적: 광고, 분석 |
| 앱 정보 및 성능 → 비정상 종료 로그, 진단 | 수집 ✔ (AdMob·ML Kit) · 목적: 분석 |
| 사진 및 동영상 | **수집 안 함** (기기 안에서만 처리, 전송하지 않음) |

※ 구글이 공개한 AdMob 데이터 공개 가이드를 최종 기준으로 확인하세요.

## 미국 출시 전에 직접 해야 할 일

1. **AdMob 콘솔 → 개인정보 보호 및 메시지 → 미국 주 규정(US states)** 메시지를 만들어 게시하세요. 그래야 캘리포니아 등에서 "개인정보 판매·공유 거부" 안내가 앱에 뜨고, 앱의 "광고 동의 변경" 버튼도 나타나요.
2. 플레이 콘솔 → **국가/지역**에서 미국을 추가하세요.
3. (완료) 개인정보처리방침 문의 이메일: contact@yeoncompany.com
4. 영어 스크린샷: 휴대폰 언어를 영어로 바꾸고 광고가 안 보이게 찍어 주세요.
5. **콘텐츠 등급** 설문과 **타겟층(만 13세 이상)** 을 설정하세요.
